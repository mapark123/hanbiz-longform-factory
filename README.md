# 한비즈 롱폼 영상 공장

대표가 찍은 녹화 한 편을 **컷편집 → 뒷 장면(움직이는 그래픽) → 효과음 → 자막 → 4K 60fps 최종본**까지 만드는 공정과 도구입니다.
"메타광고 돌리면 무조건 오는 사기 4가지"(2026-11-07, 9분 2초)를 만들면서 대표 피드백 100번 넘게 받아 다듬은 그대로를 담았습니다.

- 결과물 예시: 장면 46개 · 효과음 163개(같은 파일 반복 0) · 자막 353줄 · 개인정보 가린 실제 캡처 17장 · 컷씬 23장
- 핵심 원칙 다섯 줄
  1. **무음만 자른다** — 말 끝음은 절대 깎지 않는다(-48dB 까지 말로 친다)
  2. **화면은 움직이는 그래픽이 주인공** — 글 카드 X · 2초 넘게 멈춤 X · 한 번에 한 곳만 정가운데
  3. **효과음은 한비즈 라이브러리에서만, 같은 파일 두 번 X** — 대표 사용음(A★)부터 · 목소리는 한 샘플도 안 줄임
  4. **자막은 문장(뜻) 단위 두 덩어리** — 말소리 쉼에 맞춰 자르지 않음 · 귀 높이 · 정가운데 · 핵심만 빨강/노랑
  5. **드리기 전에 잰다** — 무음 검사 · 이음매 받아쓰기 · 정지 감지 · 얼굴 원 픽셀 대조 · 프레임 겹침 검사

## 빠른 시작

```bash
git clone https://github.com/mapark123/hanbiz-longform-factory.git
cd hanbiz-longform-factory
cp -r _틀 롱폼_새영상이름            # 새 영상 프로젝트
# 롱폼_새영상이름/설정.json 채우기(원본녹화·기준영상·얼굴 원·장 색)
# 녹화를 롱폼_새영상이름/소통/ 에 넣고 → 기준/01_작업순서.md 대로
```

설치할 것은 `설치.md`. 클로드 코드를 쓰면 `스킬/hanbiz-longform` 을 `~/.claude/skills/` 에 복사하세요.

## 들어 있지 않은 것 (일부러 뺌)

- **효과음 파일** — Mixkit·効果音ラボ 라이선스상 파일 재배포 금지. 한비즈 효과음 라이브러리(`한비즈_효과음_등급별.zip`, 직원 전용)를 따로 받아 풀고 `설정.json` «효과음라이브러리» 또는 환경변수 `HANBIZ_SFX_LIB` 에 경로를 적습니다.
- **수강생 원본 캡처·대표 녹화·완성 영상** — 개인정보·용량. 예시 폴더엔 원고·배치도·코드만 있습니다.
- 영상·소리·그림 파일은 `.gitignore` 로 자동 제외됩니다(커밋해도 안 올라감).
