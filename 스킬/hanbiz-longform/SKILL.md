# 한비즈 롱폼 영상 공장

저장소: https://github.com/mapark123/hanbiz-longform-factory (비공개 · 주소 받은 사람만)

## 시작 전 반드시 읽는다
1. 저장소 `기준/01_작업순서.md` — 단계·명령·각 단계에서 대표에게 보여 줄 것
2. `기준/02_피드백모음.md` — 대표 원문과 규칙 (특히 B 컷편집 · C 화면 · E 자막)
3. `기준/03_사고사전.md` — 같은 사고를 다시 내지 않기
4. 예시 `예시_메타사기4가지/` — 배치도(46장면·163효과음)·장면 코드·자막 원고

## 절대 규칙 (어기면 다시 하게 됨)
- **무음만 자른다.** 말 끝음 깎으면 대표가 바로 잡아낸다 → 드리기 전 무음검사(버린 곳 안 소리 0)·이음매 받아쓰기·컷본 전체 받아쓰기
- **0.3초짜리 혼잣말은 의심부터** — 조각만 받아써 헛것이면 앞 말 꼬리
- **화면 = 움직이는 그래픽이 주인공** · 글 카드 X · 2초 넘게 멈춤 X(정지 감지로 잼) · 한 번에 한 곳만 정가운데 · 얼굴 원 자리와 자막 띠는 비움 · 컷씬은 장면마다 한 장씩
- **실제 캡처는 개인정보 가린 사본만** · 새로 그린 화면엔 «재현» 표시
- **효과음은 한비즈 라이브러리만 · 같은 파일 두 번 X** · A★(대표 사용음) → A → B·C · **목소리는 한 샘플도 안 줄임**
- **자막은 문장(뜻) 단위 두 덩어리(18자 안팎)** · 원고는 직접 씀 · 귀 높이 · 정가운데 · 빨강(위험·사기)/노랑(숫자·핵심)
- 장면 움직임 시각 = 그 장면 효과음 시각 = 낱말 시각(싱크)
- 숫자는 «쟀다/추정» 구분 · 남은 시간은 단계별로
- **정리 = 이번 결과물 더미만.** 코드·도구·라이브러리는 지우지 않는다
- 끝나면 영상 재생 + 폴더(파일 선택) 띄우기 · 드라이브 올리면 바이트 크기 대조

## 새 영상
```bash
cp -r _틀 롱폼_이름   # 설정.json 채우기 → 녹화를 소통/ 에 → 기준/01_작업순서.md 0~9단계
```
