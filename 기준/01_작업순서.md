# 작업 순서 — 녹화 한 편에서 4K 최종본까지

> 모든 명령은 프로젝트 폴더(`롱폼_이름/`)에서. 파이썬은 `python -X utf8`.
> 각 단계 끝의 **대표에게 보여 줄 것**을 건너뛰지 않는다. 대표 확인 없이 다음 단계로 크게 넘어가면 다시 하게 된다.

## 0. 시작
1. `cp -r _틀 롱폼_이름` → `설정.json` 채우기(제목·원본녹화·기준영상·장 색)
2. 대본은 대표가 확정한 한 파일만(`대본.md`). 대표는 대본을 그대로 읽지 않는다 → **정답은 대표가 실제로 한 말**.
3. 녹화는 `소통/` 에 받는다. 저장은 D(빠른 디스크). 결과물만 남기고 중간물은 마지막에 지운다.
4. **화면 방식 고르기** — 0~2단계(받아쓰기·컷)는 둘 다 같다. 3단계부터 갈린다.

| 방식 | 언제 | 화면 | 순서 |
|---|---|---|---|
| **A. 뒷 장면** | 대표 채널 · 화면 캡처 설명이 많은 영상 | 검은 바탕 + 왼쪽 아래 얼굴 원 + 움직이는 그래픽 | 3~9단계 |
| **B. 풀화면** | 원장님·외부 출연자 · 얼굴이 주인공인 영상 | 출연자 화면 가득 + 종이 판이 반반으로 밀려 들어옴 + 예능 큰 자막 | 맨 아래 «풀화면 방식» P1~P7 |

## 1. 받아쓰기·분석
```bash
ffmpeg -i 소통/원본.MOV -ac 1 -ar 16000 편집/a16k.wav
ffmpeg -i 소통/원본.MOV -ac 1 -ar 48000 편집/a48k.wav
python -X utf8 편집/_도구/받아쓰기.py 편집/a16k.wav 편집/words.json        # 전체 (large-v3)
python -X utf8 편집/_도구/숨단위받아쓰기.py                                 # 쉼마다 잘라 5초 안팎씩 — 더듬은 말이 그대로 나옴
python -X utf8 편집/_도구/구간단어.py 26:32 143:149                         # 헷갈리는 구간만 잘게 다시(단어 시각)
```
- 전체 받아쓰기는 다시 말한 부분을 합쳐 매끄럽게 고쳐 버린다 → **숨 단위 + 구간 재받아쓰기**로 확인
- 대본과 대조해 «대본과 다르게 한 말 · 대본에 없던 말(화면 재료가 없을 수 있음) · 빠진 말» 목록

## 2. 컷편집 (무음만 · 끝음 보호)
1. `편집/_도구/컷만들기.py` 의 `지울말`(시작초, 끝초, 이유)에 «다시 말한 앞 판·혼잣말»을 적는다. 시각은 구간단어 결과로.
   - **0.3초짜리 혼잣말은 의심부터**: 그 조각만 받아써서 «영상편집 박진주»·«감사합니다» 같은 헛것이 나오면 앞 말의 끝 글자다 → 지우지 않는다
   - 경계는 실제 소리 막대(-40dB 아래 틈)에 맞춘다. 단어 사이 틈이 없으면 앞뒤를 따로 받아써 어느 쪽 글자인지 확인
2. `python -X utf8 편집/_도구/컷만들기.py` → `컷구간.json` · `컷보고.txt`
   - 쉼: 0.30초 넘으면 줄임 · 말 끝은 -48dB 까지(최대 0.25초) 말로 침 · 여유 앞 0.04 / 뒤 0.06초 → 쉼 중간값 0.16초 안팎(대표 기준 0.15~0.2초)
3. `python -X utf8 편집/_도구/컷적용.py 컷본_v1.mp4` (프레임 맞춤 · 소리 5ms 페이드 · yuv420p)
4. 검사 넷 — **전부 통과해야 대표에게 보냄**
   - `python -X utf8 편집/_도구/무음검사.py` → 버린 곳 안에 «지운 말·숨 말고» 소리가 있으면 실패(0곳이어야)
   - `python -X utf8 편집/_도구/잘림전수검사.py` → 이음매마다 «남긴 끝까지» vs «0.35초 더» 받아쓰기 비교. 말이 달라지는 곳은 원본 소리 곡선과 조각 받아쓰기로 하나씩 판정(무음검사는 숨으로 판정한 곳을 못 잡는다)
   - `python -X utf8 편집/_도구/이음매확인.py 컷본_v1.mp4` → 말 이음매마다 앞뒤 2.5초 받아써서 «앞 ‖ 뒤» 를 사람 눈으로 읽음
   - 컷본 전체 받아쓰기로 맥락 확인(같은 말 겹침·어색한 흐름) + `더듬찾기.py` 로 낱말 반복 후보
5. **대표에게 보여 줄 것**: 길이(전→후) · 지운 곳 수·초 · 가장 긴 쉼 · 판단해서 고른 것(끝인사 판 등) · 대본에 없던 말
6. 대표가 직접 더 자르면(캡컷) 그 판을 기준영상으로 받는다. 잘린 곳이 생기면 소리 맞대기로 옮김 값(예: 139.55초 뒤 -0.777초)을 재서 배치도 시각을 옮긴다.

## 3. 뒷 장면 구상 → 대표 확인
1. 기준영상(대표 최종 컷, 얼굴 원·검은 바탕)을 받아써 `화면/말시각.json` — `python -X utf8 화면/_도구/말시각만들기.py`
2. `화면/_도구/배치도.py` 에 장면마다 (시작, 끝, 제목, 화면 구상, 재료, 효과음[(닻 낱말, 파일, 왜)]) — 예시 `예시_메타사기4가지/화면/배치도_예시.py`
   - `python -X utf8 화면/_도구/배치도.py` → 같은 파일 두 번·닻 못 찾음·파일 없음을 «문제»로 출력 → 0 이어야
3. `python -X utf8 화면/_도구/콘티만들기.py` → `화면/콘티_뒷장면_효과음.html` (장면별 말·화면·재료 썸네일·효과음 ▶ 듣기)
4. **대표에게 보여 줄 것**: 콘티 한 장. 그리고 «이미지만 까는 게 아니라 움직이는 그래픽이 주인공» 을 말로 분명히(오해 받은 적 있음). 짧은 실제 움직임 샘플이 가장 빠르다.

## 4. 개인정보 가리기 (재료 준비)
- 원본은 `재료/실제사례/` 그대로 · 가린 사본 `재료/실제사례_가림/` 만 영상에 씀
- `재료/_도구/가리기.py` 의 좌표는 **글자 픽셀로 잰다**(눈짐작 X — 첫 글자가 남거나 줄을 비껴간 적 있음) → 가린 뒤 한 장씩 확대해서 확인
- 가릴 것: 수강생 이름·프로필 사진·이메일·페이지 이름/ID·업체명·대표 회사명(대표가 보여도 된다 하기 전까지) · 사기꾼 쪽 주소·번호는 짚어야 하니 남김

## 5. 장면 만들기
- `화면/뒷화면.html` + `엔진.js`(배경·부품·장면 묶음) + `장면_부품.js` + `장면_가/나/다.js`(장면 코드)
- `python -X utf8 화면/_도구/데이터만들기.py` (배치도를 고칠 때마다) → 데이터.js · 선명 캡처 사본
- 장면 코드 규칙: 그림은 시각 t 만으로 정한다(조각으로 나눠 찍어도 같아야) · **움직임 시각 = 그 장면 효과음 시각(s.ev)** → 소리 나는 순간 그림이 움직임
- 미리 보기: `node 화면/찍기.mjs 뒷화면 --미리 3,10.5,21.4` → `python -X utf8 화면/_도구/미리판.py` (얼굴 원 자리 초록 원으로 표시)

## 6. 찍기 (4K 60fps)
```bash
node 화면/전부찍기.mjs 뒷화면 --동시 12        # 12초 조각 · 120장 찍어 60fps 모션블러 · 9분 = 약 52분(RTX 5070 Ti · 62GB)
ffmpeg -i 화면/찍은것/뒷화면.mp4 -vf "scale=480:270,fps=15,freezedetect=n=0.0008:d=1.5" -an -f null -   # 정지 감지
node 화면/조각고쳐찍기.mjs 8,21,38             # 고친 장면이 걸친 12초 조각만 다시 찍고 이어 붙임
```
- 정지 감지에서 2초 넘는 곳은 고친다(다가가는 카메라·둥둥 · 같은 화면 흔들기 꼼수 X)
- 이어 붙인 뒤 프레임 수·겹침 검사(조각고쳐찍기가 segment 방식이라 겹침 0)

## 7. 효과음 섞기 (목소리 그대로)
```bash
python -X utf8 화면/_도구/효과음섞기.py   # → 화면/_소리_최종.wav · 효과음기록.txt
```
- 목소리 이득 1.0(한 샘플도 안 줄임 — «합 − 효과음 = 원본» 차이 1e-7 수준 확인) · 분류별 목표 최대치 · 소리 시작점을 닻에 맞춤
- 넘칠 순간엔 효과음만 줄임 · 목소리 큰 순간은 ±0.15초 안에서 피해 옮김(화면 싱크 허용 ±0.3초 안)

## 8. 자막 (대표가 맡기면)
1. 원고 `화면/자막/원고.txt` 는 **내가 직접 쓴다**: 문장 하나 → 뜻이 이어지는 두 덩어리(18자 안팎) · 받아쓰기 오타 고침 · 색은 `{r:위험·사기}` `{y:숫자·핵심}`
2. `python -X utf8 화면/_도구/자막맞추기.py` (글자 단위로 말 시각에 맞댐 · 일치율 80% 아래는 «문제»)
3. `python -X utf8 화면/_도구/자막정렬.py` (강제 정렬로 줄마다 말 시작·끝을 재서 시각 고침 — whisper 시각은 0.2초 안팎 일러 자막이 먼저 뜸 · 보고의 «사람이 볼 곳»은 소리로 확인)
4. `node 화면/자막/자막그림.cjs` (귀 높이 위 862 · 정가운데 · 얼굴 원에 닿으면 «넘침»)
5. 시안 한 장(실제 화면 위 자막) 먼저 보여 주고 위치 확인받기

## 9. 합치기·검수·전달·정리
```bash
python -X utf8 화면/_도구/최종합치기.py   # 뒷 화면 + 얼굴 원(원만 도려냄) + 소리 + 자막 → 완성/제목_최종_4K60.mp4 (약 11~13분)
python -X utf8 화면/_도구/최종검수.py     # 형식 · 얼굴 원 픽셀 대조(1.5 안팎이면 압축 잡음) · 효과음 순간 화면 모음 · 소리 크기
```
- 드라이브: 인터넷 창으로 올리고 드라이브 쪽 파일 크기가 바이트까지 같은지 확인
- 정리: **이번 작업이 만든 결과물 더미만** 지운다(중간 영상·컷본·렌더 조각·소리 믹스·검수 그림·로그). 도구·코드·라이브러리는 절대 같이 지우지 않는다. 지우기 전 «지울 것 / 남는 도구» 목록을 보여 준다.

# 풀화면 방식 (B) — 출연자 화면 가득 + 종이 판 + 예능 자막

> 첫 작업: 유윌비의원 2편 «화장 계속 뜨는 이유 3가지»(2026-11-09, 5분 18초). 실제 콘티는 `예시_유윌비2편/화면/풀화면콘티_예시.py`.
> 화면 구성: 출연자 영상은 자르지 않고 화면 가득 → 설명할 때 오른쪽에서 종이 판이 찢어진 가장자리로 밀려 들어와 반반 → 판 위에 사진(인화+테이프)·태그·노란 포스트잇·도장·펜 동그라미/X/화살표·원인→결과 단계가 **말하는 낱말에 맞춰** 붙는다.
> 판 밖: 예능 큰 포인트 자막(노랑/빨강) · 파란 Q 카드 · 왼쪽 위 코너 번호 · 손글씨 드립 · 이름표 · 오른쪽 위 로고 · 아래 사선 방송 자막 띠.

## P1. 재료
- `설정.json` 의 «기준영상» = 컷 끝난 출연자 영상(얼굴 원 아님, 원본 화면 그대로) · «제목» = 결과 파일 이름
- 로고 `재료/로고.png`(오른쪽 위 고정) · 자료 사진 `재료/이미지/번호_이름.png`
- 사진은 **글보다 이미지 위주**. 코덱스로 실사를 하나씩 뽑는다 — 프롬프트 쓰는 법과 43장 실례: `예시_유윌비2편/재료/이미지목록_예시.py`(얼굴 접사는 «눈은 보이지 않는다» · 브랜드·글자 없음 · 실존 인물 닮지 않게)

## P2. 자막 원고 → 낱말 시각
1. `화면/자막/원고.txt` 직접 쓴다 — 한 줄 = 화면에 뜨는 한 덩어리(길면 뜻 단위로 두 줄로 나눔) · 썸네일 문구·대본에만 있고 말 안 한 문장은 넣지 않는다
2. `python -X utf8 화면/_도구/말시각만들기.py` (whisper 낱말 시각 — 대략 위치용)
3. `python -X utf8 화면/_도구/풀화면시각.py` → `화면/풀화면시각.json` (원고 낱말을 소리에 **강제 정렬** · 40초 묶음 · «경고» 0 이어야 · 필요: srt-align 스킬)

## P3. 콘티 = 코드 한 파일
- `화면/_도구/풀화면콘티.py` 에 장면을 적는다(부품 설명: `풀화면부품.py` 맨 위). 시각은 숫자로 안 쓰고 **원고 낱말로** 찾는다: `W('줄 조각', '낱말')`
- 기본값(대표 확정):
  - 장면 설명 = 그 장면 **사진**을 띄운다 · 글(태그)은 상세 이해가 필요할 때만 · 한 판에 사진 1~3장(슬롯 큰/왼위·오아래/세1~3)
  - 큰 포인트 자막이 뜨면 **포인트 + 옆 자료만** — 서브 문구 X · 아래 자막 X(자동으로 숨김)
  - 빨강 포인트 = 하지 마세요·위험 / 노랑 = 핵심·처방
  - Q 카드가 뜨는 동안 그 질문 줄 자막은 숨긴다(`숨길=`)
  - 빈 종이 금지 — 판은 첫 자료 0.75초 전에 열고, 다음 장은 0.5초 전에 넘긴다(부품이 자동)
- `python -X utf8 화면/_도구/풀화면콘티.py` → `화면/풀화면데이터.js` + `화면/배치도.json`(효과음) · «없는 이미지 [] · 효과음 부족 [] · 판 겹침 []» 이어야

## P4. 미리 보기 → 대표 확인
```bash
python -X utf8 화면/_도구/풀화면미리모음.py 화면/_미리      # 자료가 다 나온 순간마다 실제 화면 위에 합성 → 모음0.jpg … (40장씩)
node 화면/풀화면찍기.cjs 미리 화면/_미리/낱장 95.5,240     # 특정 순간만 투명 PNG
```
- 큰 작업 전 **짧은 움직임 샘플**(10~30초)을 먼저 보여 준다. 고칠 곳은 콘티만 고쳐 다시 돌린다(화면·효과음이 같은 숫자를 읽으니 싱크 유지)

## P5. 효과음
- 콘티가 역할만 정하면 `풀화면부품.효과음고르기()` 가 라이브러리에서 고른다
  - 자료 등장(사진·표·단계·옆 자료) = `마우스 클릭.mp3` **고정** · 종이 장 넘김 = `종이넘기는 소리.mp3` **고정**
  - 판 전환 = 이름이 휙·whoosh 계열이고 **0.25초 안에 최대가 되는** 소리만 돌려 씀(느리게 차오르는 소리는 판보다 늦게 들림)
  - 나머지(쿵·띵·펜·도장·반짝·코믹·물) = 같은 파일 두 번 X · A★ 먼저 · 코드로 만든 소리 X
- 섞기: `효과음섞기.py`(목소리 이득 1.0 · `설정.json` «효과음옮김_최대» 를 **0.04** 로 — 싱크 우선) · 크기 확인 `python -X utf8 화면/_도구/효과음검사.py`
