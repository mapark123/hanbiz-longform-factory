# 사고 사전 — 실제로 터진 기술 사고와 고친 법

## 받아쓰기·컷
- **전체 받아쓰기는 다시 말한 부분을 합쳐 버린다** → 숨 단위(쉼마다 5초 안팎) + 헷갈리는 구간 잘게(`구간단어.py`)
- **받아쓰기가 «빠졌다»고 한 말이 실제론 있음**(100% 사기니까·선납으로 받습니다 등 4곳) → 빠졌다고 판단하기 전 반드시 잘게 다시
- **짧은 조각 받아쓰기는 헛것을 만든다**: 0.3초 조각에서 «영상편집 박진주»·«감사합니다»·«다음 영상에서 만나요» → 지울 말이 아니라 앞 말 꼬리라는 신호
- **경계를 «창 안 최솟값»에 붙이면** 말 가운데 살짝 작아진 곳(-29dB)을 골라 지운 말 꼬리가 남음 → «가장 가까운 조용한 점(-35~-40dB)»
- **여유(패딩)가 지운 구간 안으로 들어가** 지운 말 꼬리를 되살림 → 여유가 지운 곳을 못 넘게
- **소리 덩어리를 -38dB 로 끊으면** «요~» 같은 말 끝 감쇠를 무음 취급 → -48dB 까지 말로 침
- **ffmpeg select 식에 + 145개** → "Cannot allocate memory" → 12개씩 괄호로 묶기 · 소리는 numpy 로 잘라 붙이고 이음매 5ms 페이드
- **숨 판정을 고정값(-30dB)으로 두면** 말이 작은 녹화에서 끝말이 숨으로 지워짐(«없고요» -34dB) · 무음검사는 숨을 빼고 보니 못 잡음 → 녹화의 말 크기 기준으로 판정 + 잘림전수검사 필수
- **컷적용이 프레임 번호로 자르는데 FPS 30 고정** → 60fps·가변 원본은 화면만 엉뚱한 자리가 잘림 → 필터 앞에 `fps=30`
- **ffmpeg 9 에서 `-filter_script:v` 삭제** → `-/filter:v 파일`
- **아이폰 HEVC 10비트 원본** → h264_nvenc 가 High 10 으로 찍혀 윈도우 플레이어가 깨진 파일이라 함 → 필터 끝 `format=yuv420p`

## 캡컷 판 받기
- 캡컷은 내보낼 때 **밝기를 바꾸고(178→158) 소리를 0.705배**로 줄였다 → 내 판에서 조각을 끼울 땐 색 변환표(LUT)와 배율을 맞춰야 이음매가 안 보임
- 캡컷 프로젝트 `draft_content.json` 은 암호화 안 됨 → 컷 지점을 정확히 읽을 수 있음(단 편집 중엔 비어 있을 수 있음 → `template-2.tmp`·`.bak`)
- 대표가 더 자른 판은 **소리 맞대기(교차상관)**로 어디가 몇 초 잘렸는지 잰다(예: 139.55~140.35 «이걸,» 0.8초)

## 장면·찍기
- **프리텐다드가 맑은 고딕으로 찍힘**(11/4) → 찍기 도구가 글자 폭을 재서 출력([글꼴] 줄 · 두 값이 달라야 정상)
- **캡처를 아이폰 틀 안에 넣으면 글자가 안 보임** → 카톡·DM 캡처는 큰 카드(폭 560~660)로 · 원본이 작으면 3배 선명 사본
- **재현 표시가 창 단추(빨강·노랑·초록)와 겹침** → 오른쪽 위
- **카드 번호가 두 줄로 넘어가 가림 막대 밖으로 삐져나옴** → `white-space:nowrap` + 폭 재기
- **이음매에 같은 그림이 이어질 때 페이드가 겹치면 어두워짐** → 엔진 `이음` 목록(앞 장면과 같은 그림이면 페이드 없이)
- **정지 감지에서 3초·2.1초 멈춤** → 다가가는 카메라·둥둥(쉼 함수) 추가 후 그 장면 조각만 다시 찍기
- **조각 이어 붙일 때 concat inpoint/outpoint 로 자르면 이음매마다 프레임 3장 겹침(96장)** → 옛 영상은 `-f segment`(키프레임 단위)로 잘라 이어야 겹침 0. 이어 붙인 뒤 항상 프레임 수·겹침 검사
- **4K 14개 동시** = 메모리 커밋 98% → 12개가 안전선(62GB 기준)

## 효과음
- 대표가 목소리를 이미 0dB 넘게 올려 둠(+0.62dBFS) → 겹침 줄이기가 142초 → 목소리 큰 순간을 피해 효과음을 ±0.15초 옮겨 해결
- 라이저·스윕은 처음이 원래 작다 → «첫 0.25초가 작다»만으로 깎였다고 판단하지 말 것(목소리 여유 곡선으로 판단)
- 등급표의 «고역 셈» → 7kHz 위 -4dB · «순간음» → 6ms 페이드인

## 자막
- **자동 분할은 받아쓰기에 마침표가 없어 뜻 중간에서 끊음**(«그 / 메일», «올 / 때마다») → 원고는 사람이(클로드가) 직접 문장 단위로
- 색 표시 벗기는 정규식 치환에 `\1` 을 셸·파이썬 문자열로 넘기다 **글자까지 지워짐** → 치환은 `lambda m: m.group(1)`
- 자막 위치를 얼굴 피해 오른쪽(1110)으로 했더니 «중앙 정렬 맞지?» → 줄을 짧게 해서 정가운데(960)

## 풀화면 방식
- **whisper 낱말 시각으로 자막·자료를 맞추면 0.2초 안팎 먼저 뜸** → 원고를 소리에 강제 정렬(`풀화면시각.py`). 한 번에 다 넣으면 오류가 번짐 → 40초 묶음 · 다음 묶음은 앞 묶음 끝에서 시작 · 다음 묶음 머리 3낱말을 같이 넣고 버림(끝이 늘어나는 것 방지)
- **큰 자막 시작과 거의 같이 시작해 그 안에서 끝나는 아래 자막** → 한순간 깜빡임 → 그 줄은 자동으로 숨김
- **판이 열렸는데 첫 자료가 1초 넘게 늦게 붙음 = 빈 종이** → 판 여는 시각을 첫 자료 기준으로 당김(`풀화면부품.판`)
- **판 전환음이 판보다 늦게 들림** → 소리가 천천히 차오르는 파일이었다. 0.25초 안에 최대가 되는 휙 계열만 쓰고 그 안에서 돌려 씀
- **효과음 라이브러리를 못 찾은 채 콘티를 돌려 배치도.json 이 빈 걸로 덮임** → 부족하면 배치도를 그대로 둠 · 섞기 실패하면 렌더 중단(옛 소리로 몰래 넘어가지 않게)
- **환경변수 `HANBIZ_SFX_LIB` 가 설정.json 보다 먼저** 읽힌다 → PC 에 옛 경로가 남아 있으면 «라이브러리 없음». 값을 확인하거나 지운다
- **효과음 옮김 ±0.15초면 화면 동작과 어긋나 보임**(풀화면은 자료가 낱말에 딱 붙어서) → ±0.04초만
- **긴 자막 한 줄이 화면 폭을 넘음** → 원고에서 뜻 단위로 두 줄로 나눈다(쉼표·«~는데» 뒤)
- **고친 내용을 일회용 «고침N.py» 패치로 쌓으면** 다음 영상에서 다시 못 씀 → 규칙은 `_틀` 의 부품·HTML 에 바로 넣는다

## 셸·윈도우
- bash 변수 이름에 한글 금지(`옛=…` 은 명령으로 읽힘) · heredoc 에 역슬래시·정규식 넣지 말 것 → 파일로 써서 실행
- 파이썬이 쓴 파일은 줄 끝이 `\r\n` → 다른 도구가 정규식으로 읽다 실패 → 실행해서 읽거나 `newline=''`
- 데이터 파일을 정규식 `\[.*?\]` 로 뽑으면 배열 안 첫 `]` 에서 끊김

## 정리
- **«도구 지우기»를 «결과물 더미 지우기»로 읽어야 했는데 코드까지 지움** → 깃 자동저장이 삭제를 기록하기 전이라 `git checkout HEAD -- <파일>` 로 86개 복구. 지우기 전 «지울 것 / 남는 도구» 목록을 보여 주고, 지운 직후 `git status` 로 코드가 지워지지 않았는지 확인
